# Neurons at Play animal library

This repository contains 175 friendly animal illustrations for Neurons at Play games. Each PNG contains exactly one animal on a transparent background.

## Using the files

- Use the individual PNG from the `animals/` folder; filenames are lowercase and use hyphens between words.
- The 24 supplied originals are 640 × 640 pixels.
- The 151 collection additions are 1254 × 1254 pixels.
- Preserve the transparent background when resizing or embedding an image.
- See `catalogue.json` for dimensions, file sizes, groups, and SHA-256 checksums.
